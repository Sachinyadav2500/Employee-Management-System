# 📖 Overview

The **Employee Management System (EMS)** is a full-stack web application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. It streamlines employee management by allowing administrators to manage employee records, departments, salaries, and leave requests through a secure and user-friendly interface.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Sachinyadav2500/Employee-Management-System.git
```

```bash
cd Employee-Management-System
```

---

## Install Frontend

```bash
cd frontend
npm install
```

---

## Install Backend

```bash
cd ../backend
npm install
```

---

# ⚙️ Environment Variables

Create a `.env` file inside the **backend** folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

---

# ▶️ Run Backend

```bash
npm run dev
```

---

# ▶️ Run Frontend

```bash
npm run dev
```
